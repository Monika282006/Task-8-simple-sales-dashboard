# Task 8: Simple Sales Dashboard

## Objective
Create an interactive Power BI dashboard to analyze sales performance by month, region, and product category.

## Dataset
Sample Superstore dataset containing:

- Order Date
- Ship Date
- Region
- Category
- Sales
- Profit

## Dashboard Visuals

- Line Chart: Sales trend over time
- Bar Chart: Sales by Region
- Donut Chart: Sales by Category
- Region dropdown slicer for interactive filtering

## Key Insights

- West region generated the highest sales.
- Technology was the top-selling category.
- Monthly sales were strongest toward the end of the year.

## Files

- `Superstore_Sales_Dashboard.pbix` — Power BI dashboard file
- `Superstore_Sales_Dashboard.pdf` — Dashboard PDF export
- `sales_dashboard_insights.txt` — Written insights

## Tools Used

- Microsoft Power BI Desktop
- Sample Superstore CSV dataset
